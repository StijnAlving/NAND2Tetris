This is a learning project. It is in no way optimized. The entire project is written by hand and without the interaction of an LLM, just classic learning. 

Each .py file is a physics simulation
A .SRA file is a stack based software file interpreted by SRA.py in this REPO. It simulates the program language that we might use on a machine.
The machine itself is a soldering of gates and circuits all constructed in the .hard files, which are interpreted by the hard.py interpreter.
Both .hard and .sra files have very limited logic build into them, creating a need to build that logic up myself.
